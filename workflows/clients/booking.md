# Отдел: Клиенты

## Автоматизация: Приём записи

Степень свободы: средняя. Агент самостоятельно обрабатывает типовые запросы и переносы на свободное время. Неясные услуги, конфликтные записи, VIP-исключения и отмены день-в-день передаются владельцу.

```text
i входящее: Instagram Direct / WhatsApp
│
├─ task1 «Понять запрос»                         @Агент-Администратор
│  r:данные(карточка клиента)
│  r:знания(услуги, цены, длительность, тон)
│
├─ task2 «Найти свободные окна»                  @Агент-Администратор
│  r:данные(графики мастеров, календарь визитов)
│
├─ if окно есть?
│  ├─ [да] task3 «Записать визит»                @Агент-Администратор
│  │  w:данные(визит, мастер, услуга, статус=confirmed)
│  │  a:интеграции(CRM, Instagram / WhatsApp)
│  │  └─ d «Напоминание о визите»
│  │     └─ End: успех → визит создан, клиенту отправлено подтверждение
│  │
│  └─ [нет] task4 «Предложить ближайшие окна»    @Агент-Администратор
│     a:интеграции(Instagram / WhatsApp)
│     └─ wait: ответ клиента (24ч)
│        ├─ [клиент выбрал окно] → task3
│        ├─ [клиент хочет ждать] End: возврат → запись в лист ожидания
│        ├─ [запрос спорный] escalation          @Владелец
│        │  └─ End: передача → карточка во Входящих
│        └─ [нет ответа] End: отказ → пометка администратору
```

### Ресурсы агента

- Память: история диалогов, прошлые предпочтения клиента.
- Знания: услуги, цены, длительность, правила записи, tone of voice.
- Данные: карточки клиентов, графики мастеров, календарь визитов, лист ожидания.
- Интеграции: Instagram Direct, WhatsApp, CRM/календарь.
- Инструменты: извлечение сущностей из сообщения, подбор слотов, генерация ответа.
